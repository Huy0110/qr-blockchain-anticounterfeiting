# perf-verification

**Reproduces:** Paper Table 3 rows 2–4 — "Public scan ~5 s, Private valid ~30 s, Private invalid ~4 s".

## Sub-experiments

| Script                    | Endpoint                | Outcome          | Paper row |
| ------------------------- | ----------------------- | ---------------- | --------- |
| `run-public.ts`           | `GET /scan/public/:phi` | OK               | 2         |
| `run-private-valid.ts`    | `POST /scan/private`    | AUTHENTIC        | 3         |
| `run-private-invalid.ts`  | `POST /scan/private`    | COUNTERFEIT      | 4         |
| `run-private-redeemed.ts` | `POST /scan/private`    | ALREADY_VERIFIED | 4 (alt)   |

## Prerequisites

- Hub running at `HUB_BASE_URL` (default `http://localhost:3000/api/v1`).
- For `private-valid`: `VALID_SIDS_PATH` env var pointing to a file of
  `<projectId>:<secretId>` lines, one per trial. Generated by
  `pnpm exp:seed:private-valid` (or by running the management portal's
  batch wizard once and saving the unredeemed sids).
- For `private-redeemed`: same input, but the seed script must redeem
  each sid once before the experiment runs.

## Run

```sh
pnpm exp:perf-verification --trials 30 --network amoy
# or one at a time:
pnpm tsx perf-verification/run-public.ts --trials 30 --network amoy
```

## Outputs

`results/<RUN_ID>/perf-verification/{public,private-valid,private-invalid,private-redeemed}/`
each containing `raw.csv`, `summary.json`, `plot.png`.
