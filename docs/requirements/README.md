## How to use this index

- **Implementing a feature?** Open the corresponding `features/<name>.md` for the full spec, then check `sr-mapping.md` for the SR/R it must satisfy.
- **Reviewing a PR?** Cross-check changed code against acceptance criteria in the relevant feature spec.
- **Tracking deliverables?** [sequencing.md](sequencing.md) lists phases and exit criteria.
- **Worried about a risk?** [risk-register.md](risk-register.md) groups by score and lists mitigations.
